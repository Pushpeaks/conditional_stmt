Slide 2 of 9 The Simple "If" Statement

The "If" Statement: The Midnight Craving 🍜

An if statement is a simple Yes/No Question. If the answer is YES (True), it runs the block of code. If NO (False), it totally ignores it.

🌟 Hostel Analogy:

"If it is 2:00 AM, make Maggi."
(If it's not 2 AM, just continue whatever you were doing.)

// How the computer reads it in C:
int time = 2; // 2 AM!

if (time == 2) {
printf("Water boiling... Maggi time! 🍜\n");
}
🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int time = 3;
    // Bug: Using = instead of ==
    if (time = 2) {
        printf("Water boiling... Maggi time! \n");
    }
    return 0;
}

"If-Else": Plan A or Plan B! 🔀

Sometimes doing nothing isn't an option. An else is the ultimate backup plan. If the condition is True, we do Plan A. If it's False, we automatically jump to Plan B!

🌟 Hostel Analogy (Music Rules):

"If roommate is sleeping $\rightarrow$ Use headphones! 🎧
Else (otherwise) $\rightarrow$ Blast the speakers! 🔊"

if (roommate_sleeping == 1) {
printf("Headphones on! 🎧\n");
} else {
printf("Party time! 🔊\n");
}
🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int roommate_sleeping = 1;
    // Bug: Missing curly braces for multiple statements!
    if (roommate_sleeping == 1)
        printf("Headphones on! \n");
        printf("Don't make noise!\n");
    else
        printf("Party time! \n");
    return 0;
}
Slide 4 of 9 The "Nested If" Statement

Nested If: The Double Check! 🕵️‍♂️

Sometimes you need an if inside an if. We call this a "Nested If". You only check the second condition if the first one was True!

🌟 Hostel Analogy (Contraband Checking):

"If Warden is on the floor:
   If door is unlocked:
     -> Hide the iron & kettle! 🚨
   Else:
     -> Keep quiet. 🤫"

if (warden_on_floor == 1) {
// Inside the first IF block
if (door_unlocked == 1) {
printf("Hide kettle!! 🚨\n");
} else {
printf("We are safe (shh). 🤫\n");
}
}
🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int warden_on_floor = 1;
    int door_unlocked = 0;
    // Bug: Dangling else - which if does it belong to?
    if (warden_on_floor == 1)
        if (door_unlocked == 1)
            printf("Hide kettle!! \n");
    else
        printf("Coast is clear. Game on! \n");
    return 0;
}

Else-If Ladder: Dinner Decisions 🍽️

What if you have more than two options? You build a climbing ladder of questions! It checks from top to bottom until it finds a match.

🌟 Hostel Analogy (Dinner Plan):

1️⃣ Mess menu is good? $\rightarrow$ Eat in Mess
2️⃣ Else if it's average? $\rightarrow$ Canteen Samosa
3️⃣ Else? $\rightarrow$ Zomato Delivery!

if (rating >= 8) {
printf("Mess Food\n");
} else if (rating >= 5) {
printf("Canteen\n");
} else {
printf("Zomato!\n");
}
🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int rating = 9;
    // Bug: Wrong order of conditions! What happens if rating is 9?
    if (rating >= 5) {
        printf("Canteen\n");
    } else if (rating >= 8) {
        printf("Mess Food\n");
    } else {
        printf("Zomato!\n");
    }
    return 0;
}
Slide 6 of 9 Logical Operators (AND/OR)

Logic Operators: Combining Rules! 🧠

You can check multiple conditions at once using && (AND) or || (OR).

AND &&

Both must be true!
"If I have a proxy friend AND the prof doesn't check faces $\rightarrow$ Sleep in."

OR ||

Only one needs to be true!
"If I have a fever OR I have an assignment due $\rightarrow$ Skip class."

// AND Operator (&&)
if (has_proxy == 1 && prof_strict == 0) {
printf("Zzzzz... 🛌\n");
}

// OR Operator (||)
if (is_sick == 1 || overslept == 1) {
printf("Can't make it to class! 🏃‍♂️\n");
}
🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int has_proxy = 1;
    int prof_strict = 0;
    // Bug: Semicolon right after the if condition!
    if (has_proxy == 1 && prof_strict == 0); {
        printf("Zzzzz... \n");
    }
    return 0;
}

The Switch: Vending Machine 🍫

When you want to pick an exact choice from a clean menu without writing long `else if` ladders, you use a switch statement!

🌟 Hostel Analogy (Vending Machine):

Push Button 1 for Chips, Button 2 for Red Bull.

Crucial: Don't forget your break; or you'll accidentally execute all the cases below it (like paying for chips but getting coffee poured on them)!

🐞 Buggy Code Snippet (For Demo) 
#include <stdio.h>
int main() {
    int vending_choice = 1;
    // Bug: Missing break statements!
    switch (vending_choice) {
        case 1:
            printf("Dispensing Chips \n");
        case 2:
            printf("Dispensing Red Bull \n");
        default:
            printf("Invalid!\n");
    }
    return 0;
}
